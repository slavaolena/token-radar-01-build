## About

Token Radar ranks every pre-token protocol in DefiLlama's watchlist by implied value — a model based on TVL, seven-day growth momentum, age, and category potential. Built for make.fun's "Build the best token launch radar" bounty ($1,325 USDC).

## Run

```bash
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts --input input/snapshot.json
```
